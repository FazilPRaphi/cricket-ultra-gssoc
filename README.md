# Cricket Ultra Pro X

A visually rich, arcade-style cricket game built with HTML, CSS, and JavaScript.

## Features
- Neon-themed cricket stadium visuals
- Interactive batting and bowling
- Dynamic crowd, fireworks, and commentary
- Scoreboard, run rate, and result screens
- Keyboard and button controls

## Improvements & Notes
- National flags for both teams are now shown (🇮🇳 India, 🏴 England)
- Wickets increment from 1 to 2 (2 wickets allowed)
- Chase target now decrements from 70 to 20 (instead of 100 to 0)
- Optimized for mobile and all screen sizes (responsive)
- Style remains unchanged as requested

## How to Run
Just open `cricket.html` in your browser. No dependencies required.
